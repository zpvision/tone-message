# Tone Message — AI FinKoper

Сервис определения тональности сообщений на Python/FastAPI с Ollama.
Включает Bearer API, кабинет загрузки XLSX, очереди, проверку контекста и общий ограничитель inference.

Этот репозиторий содержит очищенный снимок актуального кода сервиса.
Рабочие env-файлы, ключи, базы, переписка, эксплуатационные отчеты, модели и venv не включены.
Адреса в примерах заменены на демонстрационные. Рабочий сервис при публикации не менялся.

## Код и конфигурация

- app/ — API, классификация, inference adapter, очередь, кабинет и статические ресурсы.
- app/presets/sentiment-v1.json — промпт и checksum; метаданные серверного задания удалены.
- deploy/ — systemd/Nginx/Ollama и вспомогательные скрипты развертывания.
- scripts/ — проверки и диагностические утилиты.
- .env.example — настройки без секретов.
- API-INTEGRATION.md — существующий внешний контракт.
- MODEL-CONFIGURATION.md — параметры модели, GPU, профили, диагностика и откат.

Inference-модель задается FINKOPER_MODEL_ID, сейчас профиль настроен для gemma4:26b.
Публичный model=qwen3:8b сохранен как идентификатор совместимости API.
Он не выбирает Qwen и не является fallback. Принимается также точный ID настроенной модели.

## Запуск

Проект рассчитан на Linux. Inference выполняется внешним локальным Ollama;
Python-процесс API не загружает веса модели.

1. Создайте venv и установите зависимости из requirements.txt.
   Файл включает снимок полного серверного окружения, в том числе исторические CUDA-зависимости.
2. Настройте локальную Ollama и явно установите нужную модель.
3. Скопируйте .env.example во внешний env-файл и задайте точный MODEL_ID/URL.
4. Передайте FINKOPER_* переменные процессу и запустите python -m app.
   Само наличие .env не загружает его автоматически; systemd-шаблон использует EnvironmentFile.

Точный подсчет контекста зависит от render-only расширения установленной сборки Ollama
и native /tokenize локального runner. Обычная сборка Ollama может не поддерживать этот механизм:
в таком случае сервис возвращает ошибку, не обрезает вход и не выбирает другой tokenizer/model.
Драйверы и CUDA не следует менять без отдельной проверки необходимости.

## API

POST /api/v1/chat/completions и POST /v1/chat/completions.
Authorization: Bearer, Content-Type: application/json, HTTPS.
Один запрос содержит JSON-массив item/text внутри строки user.content.
Одиночное сообщение — массив с одним элементом.
Ответ сохраняет исходные item и порядок; tone: negative=0, neutral=1, positive=2.

Создание ключа: python -m app.api_keys create --name client-name.
Команда печатает секрет один раз, хранилище содержит хеши. Не коммитьте ключ или базу.
Кабинет и Bearer API имеют разные механизмы авторизации; см. API-INTEGRATION.md.

## Проверки

Пять актуальных наборов дают 42 автоматические проверки без запуска модели.
В активном Python-окружении выполните из корня проекта:

~~~bash
PYTHONPATH=. python scripts/test_batch_api.py
PYTHONPATH=. python scripts/test_inference_config.py
PYTHONPATH=. python scripts/test_inference_boundaries.py
PYTHONPATH=. python scripts/test_readiness.py
PYTHONPATH=. python scripts/test_public_docs.py
~~~

Остальные scripts/ включают исторические, интеграционные и живые диагностики:
они не являются единым набором для автоматического запуска.
Перед использованием задайте свой адрес вместо ai.example.com и проверьте каталоги данных.
Живые проверки могут создавать временные ключи, работать с локальными хранилищами
или выгружать модель из памяти; запускайте их в подготовленном тестовом окружении.

## GPU и совместимость

Общие ограничения: один inference-слот и одна загруженная модель по умолчанию;
функциональные профили используют ту же модель. Все будущие функции должны использовать общий gate.
Очереди, inference и повторные попытки ограничены. MODEL_DIGEST при заданном pin проверяется
в диагностике и inference; readiness возвращает 503 при несовпадении digest.

Ни один скрипт не должен неявно выбирать Qwen. pull-qwen3.sh — отключенная совместимая заглушка,
pull-model.sh требует явного FINKOPER_MODEL_ID.
Исходные тесты, промпты и JSON-контракт сохранены; публикация не добавляет новые AI-функции.
