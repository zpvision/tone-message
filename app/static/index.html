3Настройки запуска

Ollama NUM_PARALLEL: …

Общий лимит API и кабинета: один inference-запрос одновременно. Исполнители 2 или 4 ожидают общий lock; это не параллельные GPU-вычисления. При активном API-пакете запуск XLSX временно недоступен. Глобальные настройки Ollama не меняются.

Длинные сообщения получают явную ошибку. Прогрев измеряется отдельно и исключается из основной скорости. При Thinking часть лимита ответа может уйти на рассуждение.
